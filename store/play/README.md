| 앱 아이콘 | 512×512 PNG | `icon-512.png` — 2026-10-24 새 아이콘으로 갱신 (`tool/gen_icon.py`) |
| 그래픽 이미지 | 1024×500 PNG | `feature-graphic.png`(한국어), `feature-graphic-en.png`(영어) — 2026-10-24 새 아이콘과 같은 연필 표현으로 다시 만듦 (`tool/gen_feature_graphic.py`) |

스크린샷으로 쓸 만한 장면: 시작 화면, 조준 중인 테이블, 소수 적중('소수!'와 콤보), 소인수분해 힌트, 클리어 카드(별 3개).

## 스토어 설정 (제안 — Console에서 확정)

- 앱 또는 게임: **게임** / 카테고리: **퍼즐** (교육도 맞지만 퍼즐이 경쟁 범위에 가깝다)
- 태그: 두뇌 게임, 수학, 물리 기반, 캐주얼
- 광고 포함: **아니요**
- 인앱 구매: **없음**
- 기본 언어: 한국어, 추가 언어: 영어
- 콘텐츠 등급: IARC 설문 — 폭력·선정성·도박 요소 없음 → 전체 이용가
- 대상 연령층: 13세 이상 권장(수 개념이 필요하다)

## 데이터 보안 양식

Firebase가 들어오면서(2026-10-24) '수집 없음'이 아니게 됐다. 개인정보처리방침(`store/legal/privacy-policy-ko.md`)과 같은 내용으로 신고한다.

| 데이터 유형 | 수집 | 공유 | 목적 | 선택 가능 |
|---|---|---|---|---|
| 충돌 로그 | 예 | 아니요 | 분석·오류 수정 | 아니요 |
| 진단(기기 모델·OS·앱 버전) | 예 | 아니요 | 분석·오류 수정 | 아니요 |
| 기타 앱 활동(스테이지·발사·점수 이벤트) | 예 | 아니요 | 분석 | 아니요 |
| 기기 또는 기타 ID(앱 인스턴스·설치 식별자) | 예 | 아니요 | 분석·오류 수정 | 아니요 |

- 전송 중 암호화됨: 예 (Firebase가 HTTPS로 보낸다)
- 삭제 요청 수단: 앱 삭제로 중단. 요청은 연락처 메일
- 이름·이메일·위치(정확)·연락처·사진·금융 정보: **수집 안 함**
- 순위표 점수는 Play 게임즈가 다루는 데이터다. 앱이 따로 저장하지 않는다

가운데 토막이 버전 이름이 된다(`1.0.2`). 버전 게이팅이 그 값을 비교하므로 태그가 곧 버전이다. 옛 `android-*`·`ios-*` 태그는 더 쓰지 않는다.

## 버전 게이팅 값 올리기 (PRD §2.14)

값은 `remoteconfig.template.json`에 있고 `firebase deploy --only remoteconfig --project primeattack`으로 올린다. 콘솔에서 직접 고치면 파일과 어긋나니 한쪽으로만 한다.

iOS·Android 조건이 따로 있다. 두 스토어는 심사 시간이 달라 한쪽만 먼저 올라가므로, 어긋나는 동안에는 그 플랫폼 조건값만 올린다.

`recommended_version`은 틀려도 카드 한 번이라 가볍다. 위험은 전부 `minimum_version`에 있다 — 올리기 전에 셋을 확인한다.

- [ ] 그 버전이 **해당 스토어에 실제로 올라가** 대상자가 받을 수 있는가
- [ ] Play 단계적 출시가 **100%**인가 (20% 롤아웃 중이면 나머지는 받을 수 없다)
- [ ] `minSdk`를 올린 빌드가 아닌가 (구형 기기는 업데이트를 못 받아 영영 막힌다)

하나라도 아니면 그 플랫폼은 올리지 않는다. 받을 수 없는 버전을 요구하면 앱이 잠기고 빠져나갈 길이 없다.

## 스테이지 배치 바꾸기 (PRD §2.15)

`remoteconfig.template.json`의 `stage_layout` 값을 고치고, **게시 전에 반드시** 검사기를 돌린다.

```
dart run tool/check_stages.dart            # 템플릿의 값을 검사
dart run tool/check_stages.dart 후보.json   # 다른 파일을 검사
firebase deploy --only remoteconfig --project primeattack
```

검사기는 앱이 거르는 것(스키마·개수·숫자 범위)에 더해, **앱이 거르지 못하는 손패 띠 용량**을 본다. 합성수의 소인수가 제각각이면 손패 종류가 8칸을 넘어 공이 벽 밖으로 밀려 집을 수 없다. 내장 8~12단계가 이미 정확히 8칸을 쓰므로, 합성수를 더할 때는 소인수를 나눠 쓰게 짜야 한다. 발사 한도(= 처음 손패 수)도 함께 찍히니 난이도 감을 잡는 데 쓴다.
